# «Сделай лучше» × 100

Эксперимент: уродливый сайт кофейни и 100 раз подряд один и тот же промпт «сделай лучше»
в Claude Code. Две модели - Sonnet 5.5 и Opus 5.5, обе на effort medium.

Идея - [Nate Herk](https://www.youtube.com/watch?v=DByAR5Su1Yw). Здесь мой повтор с теми же правилами.

## Результат

| | Sonnet 5.5 | Opus 5.5 |
|---|---|---|
| Время, все 100 кругов | 1 ч 14 мин | 12 ч 29 мин |
| Цена по API (прогон шёл по подписке) | $19,51 | $208,97 |
| Вызовов инструментов | 1 041 | 5 016 |
| Строк кода: старт → круг 100 | 142 → 2 983 | 142 → 26 228 |
| Веб-поисков | 0 | 0 |

## Посмотреть все 100 кругов

```bash
git clone <этот репозиторий>
cd make-it-better-x100
python3 -m http.server 8765
# открыть http://localhost:8765/viewer.html
```

Стрелки ↑↓ листают круги. «Только вехи» оставляет ключевые круги (первая анимация, первая форма,
первый canvas...). «Открыть в новой вкладке» - сайт круга на весь экран.

## Повторить на своём сайте

Нужны Python 3 и Claude Code с подпиской или API-ключом.

1. Удали мои результаты: `rm -rf stats snapshots`. Иначе скрипт решит, что 100 кругов уже пройдены.
2. Положи свой сайт в `start-site/` (или оставь кофейню).
3. Поправь промпт в `PROMPT.md`, если хочешь.
4. Запусти `./start.sh`. Оба прогона пойдут в фоне. Повторный запуск продолжает с места остановки.
5. Если упрёшься в лимит подписки, круг откатится, скрипт подождёт 15 минут и повторит его сам.

Opus на 100 кругах - это часы работы и заметная часть лимита подписки. Для пробы запусти одну модель на меньшее число кругов: `python3 run_rounds.py sonnet --rounds 10`.

## Правила, как у Nate

- Каждый круг - новая сессия: без CLAUDE.md, скиллов, плагинов, хуков, MCP и памяти
  (`claude -p --safe-mode`).
- Один промпт на все круги - `PROMPT.md`.
- Считается время, цена по API, вызовы инструментов, строки кода, картинки, веб-поиски и вехи.

## Чем отличается

- Claude работает в песочнице (bubblewrap) и пишет только в папку сайта. 100 кругов без присмотра
  с полным доступом к компьютеру - лишний риск.
- Генератора картинок в чистом Claude Code нет. С `./start.sh --images` в промпт добавляется
  строка про ключ OpenRouter из `.env` (`OPENROUTER_API_KEY=...`). Мой прогон шёл без него.

## Файлы

| Что | Где |
|---|---|
| Стартовый сайт | `start-site/` |
| Скрипт прогона | `run_rounds.py`, запуск обоих - `start.sh` |
| Копия сайта после каждого круга | `snapshots/{sonnet,opus}/r000…r100/` |
| Статистика по кругам (+ отчёт модели) | `stats/{sonnet,opus}.jsonl` |
| Страница просмотра | `viewer.html` |

Рабочие папки (`work/`) и полные логи (`logs/`) появляются при запуске и в git не кладутся.
